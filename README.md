# Compound

Small wins, compounding. A minimal, gamified personal tracker that installs as an app on Android.

- **Money (£):** income, spending, budgets, transfers to India, monthly grades, treat fund.
- **Student loan (₹):** automatic EMIs, extra payments, debt-free date, interest saved.
- **Health:** meals, water, gym and a shift rota that sets the daily calorie target.
- **Game layer:** XP, levels, momentum streaks, weekly quests and milestones across everything.

All data is stored only on the device. Nothing is sent to any server.

Code layout: `core/` is the shared engine, `trackers/` holds one file pair per tracker.
See `CLAUDE.md` for how the project is organised and how to add a tracker.
